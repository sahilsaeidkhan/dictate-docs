okay so the project is called dictate docs, it's a voice first dev tool that turns dictated notes into polished commit messages and readme sections. first, you dictate messy notes with fillers and self corrections using any voice app. second, the offline engine strips the fillers and resolves the corrections and splits run on sentences. third, you get a conventional commit message or readme sections out. to install you just clone the repo and you need python three point twelve or newer, no other dependencies. usage is you run python minus m dictate docs commit with your notes, or you start the web UI with dictate docs serve and dictate right in the browser. the engine is fully offline and heuristic based, no api keys needed, but you can plug in an openai compatible llm if you want.
